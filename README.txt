PSU C++ Data Structures & OOP Practice Lab

Upload index.html to a public GitHub repository and enable Settings > Pages > Deploy from a branch > main > /(root).

Students must type code; paste is blocked via regular browser controls. The lab runs offline and stores progress in the local browser.

Important: structured checks are NOT a real C++ compiler, and some valid alternative algorithms might be rejected. Review student objections and correct the checker as appropriate.

Contains 108 exercises across 24 topics, including short trace and Big-O answers.
